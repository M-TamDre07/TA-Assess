# Mari Refleksi Diri (MRD)

**MRD** adalah komunitas pendamping TA Assess untuk berbagi refleksi, pengalaman menggunakan asesmen, masukan produk, dan diskusi pengembangan diri secara sehat.

## Prinsip komunitas

- Gunakan ruang komunitas untuk refleksi dan diskusi, bukan diagnosis.
- Jangan membagikan data pribadi, jawaban asesmen, dokumen identitas, atau informasi sensitif anggota lain tanpa izin.
- Jangan memberi label psikologis kepada anggota lain berdasarkan hasil TA Assess.
- Hasil asesmen tidak boleh dipakai sebagai satu-satunya dasar untuk keputusan penting tentang seseorang.
- Masukan tentang bug, keamanan, dan metodologi sebaiknya disampaikan secara bertanggung jawab kepada pengelola.

## Hubungan dengan TA Assess

MRD adalah kanal komunitas sosial. Keanggotaan MRD tidak diperlukan untuk menggunakan TA Assess dan tidak menentukan skor atau hasil asesmen.

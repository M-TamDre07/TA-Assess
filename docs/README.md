# TA Assess — Dokumentasi

Dokumentasi teknis TA Assess dipisahkan berdasarkan kebutuhan agar folder `docs/` tidak menjadi daftar file panjang.

## Assessment

- `assessment/ASSESSMENT-METHODOLOGY.md` — metodologi, scoring, dan batasan instrumen.
- `assessment/QUESTION-BANK.md` — struktur dan pengelolaan Question Bank.

## Security

- `security/PRIVACY.md` — privasi dan data yang diproses.
- `security/ACCOUNT-SECURITY.md` — keamanan akun, session, dan kontrol admin.
- `security/SECURITY.md` — aturan keamanan repository dan secret.
- `security/SECURITY-DEPLOYMENT.md` — checklist keamanan deployment.

## Development

- `development/CONTRIBUTING.md` — panduan kontribusi.
- `development/COMMUNITY.md` — informasi komunitas.
- `development/REPOSITORY-STRUCTURE.md` — peta struktur repository dan aturan penempatan file.

## Deployment

- `deployment/SETUP.md` — pemasangan backend Google Apps Script dan konfigurasi deployment.
- `deployment/SEO-DEPLOYMENT.md` — checklist SEO dan discoverability.
- `deployment/PUBLISH-READINESS.md` — pemeriksaan kesiapan sebelum publikasi.

## Testing

- `testing/TEST_REPORT.md` — catatan hasil pengujian.

Halaman dokumentasi yang dibaca pengguna tetap `docs.html` di root. File Markdown di sini menjadi dokumentasi teknis untuk maintainer dan contributor.

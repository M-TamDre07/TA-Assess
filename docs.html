Untuk kontributor

TA Assess menerima kontribusi melalui GitHub. Gunakan issue untuk bug atau usulan, baca panduan kontribusi, lalu kirim pull request. Secret, token, password, dan data pengguna tidak boleh dimasukkan ke repository.

Catatan: TA Assess tetap merupakan platform self assessment. Dokumentasi ini tidak mengubah status instrumen menjadi diagnosis, sertifikasi, atau instrumen psikologi tervalidasi.
